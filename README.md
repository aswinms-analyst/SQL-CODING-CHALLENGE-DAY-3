# SQL-CODING-CHALLENGE-DAY-3

# ECommerceDB SQL Practice Project
Overview
This project demonstrates core SQL concepts using a simple E-Commerce Database. It includes schema creation, sample data insertion, and a wide range of queries covering DISTINCT, aliases, WHERE, comparison, arithmetic, logical operators, NULL checks, IN/NOT IN, BETWEEN, LIKE, and mixed conditions.

The goal is to showcase practical SQL skills for data analysis, reporting, and portfolio building.

# 📂 Database Schema
Product Table

product_id (Primary Key)

product_name

price

Sales Table

sale_id (Primary Key)

product_id (Foreign Key → Product)

quantity

sale_amount

# 🛠️ Sample Data
Products include Laptop, Smartphone, Headphones, Keyboard, Mouse, Monitor, Webcam with realistic prices.
Sales records capture quantities sold and total sale amounts.

# 🔎 Query Coverage
This project demonstrates:

DISTINCT & Aliases → Unique values, column renaming

WHERE Clause → Filtering records

Comparison Operators → >, <, >=, !=

Arithmetic Operators → Price increase, sale amount adjustments

Logical Operators → AND, OR, NOT

IS NULL / IS NOT NULL → Handling missing values

IN / NOT IN → Specific product selections

BETWEEN / NOT BETWEEN → Range queries

LIKE / NOT LIKE → Pattern matching

Mixed Queries → Exam-level combined conditions

# 🎯 Learning Outcomes
Build and manage relational databases.

Write SQL queries for filtering, aggregation, and analysis.

Apply operators and conditions to solve real-world business problems.

Strengthen portfolio with hands-on SQL practice.

# 🚀 How to Run
Copy the SQL script into your SQL environment (MySQL, SQL Server, or PostgreSQL).

Execute schema creation and data insertion.

Run queries sequentially to explore results.
